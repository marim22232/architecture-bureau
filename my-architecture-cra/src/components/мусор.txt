📁 Структура компонентов / Components Structure
src/components/UI/ (Пользовательский интерфейс / User Interface)
Компонент	Перевод	Назначение
Button	Кнопка	Интерактивные элементы для действий
Card	Карточка	Контейнеры для контента (проекты, услуги)
Input	Поле ввода	Формы, поиск, обратная связь
Modal	Модальное окно	Всплывающие окна, формы, детали проектов
Tabs	Вкладки	Переключение между категориями проектов/услуг
Accordion	Аккордеон	FAQ, списки услуг, характеристики
Slider	Слайдер	Галереи проектов, фотогалереи
Breadcrumbs	Навигационная цепочка	Навигация по сайту, "хлебные крошки"
Pagination	Пагинация	Постраничная навигация по проектам
Alert	Уведомление	Системные сообщения, ошибки, успех
Badge	Бейдж	Метки статусов, категорий, акций
Loader	Загрузчик	Индикаторы загрузки контента
Icons	Иконки	Векторные иконки для интерфейса
src/components/Layout/ (Компоновка / Layout)
Компонент	Перевод	Назначение
Header	Шапка сайта	Верхняя часть сайта с меню и логотипом
Footer	Подвал сайта	Нижняя часть с контактами и ссылками
Sidebar	Боковая панель	Дополнительная навигация, фильтры
Container	Контейнер	Ограничитель ширины контента
src/components/Sections/ (Секции / Sections)
Компонент	Перевод	Назначение
Hero	Главный экран	Верхний баннер на главной странице
Services	Услуги	Блок с перечнем услуг компании
Projects	Проекты	Галерея выполненных работ
About	О компании	Информация о компании и команде
Contact	Контакты	Форма связи и контактная информация
Testimonials	Отзывы	Отзывы клиентов
📋 Полное описание компонентов
UI Components (Компоненты интерфейса)
Компонент	Когда использовать	Примеры использования
Button	Всегда, когда нужно действие	"Заказать звонок", "Подробнее", "Отправить"
Card	Отображение проектов, услуг, новостей	Карточка проекта, карточка услуги
Input	Формы связи, поиск, калькулятор	Имя, телефон, email, сообщение
Modal	Просмотр деталей проекта, формы	Детали проекта, форма заявки
Tabs	Категории проектов, фильтры	"Все", "Дома", "Коттеджи", "Коммерческие"
Accordion	Часто задаваемые вопросы	Вопросы по строительству, этапы работ
Slider	Галерея проектов, фотографии	Фото домов, интерьеров
Breadcrumbs	Внутренние страницы	Главная / Проекты / Дома
Pagination	Список проектов, блог	Страницы 1, 2, 3...
Alert	Ошибки формы, успешная отправка	"Сообщение отправлено", "Ошибка ввода"
Badge	Статусы проектов, акции	"В продаже", "Акция", "Новинка"
Loader	Загрузка контента, отправка формы	Анимация загрузки проектов
Layout Components (Компоненты макета)
Компонент	Когда использовать	Примеры использования
Header	На всех страницах	Логотип, меню, контакты
Footer	На всех страницах	Контакты, соцсети, карта сайта
Sidebar	Блог, каталог проектов	Фильтры, категории, похожие проекты
Container	Все секции	Обертка для контента
Sections (Секции страниц)
Компонент	Где используется	Содержит
Hero	Главная страница	Заголовок, подзаголовок, кнопки CTA
Services	Главная, Услуги	Карточки услуг, иконки, описания
Projects	Главная, Портфолио	Сетка проектов, фильтры, изображения
About	О компании	Текст о компании, преимущества, команда
Contact	Контакты	Форма связи, карта, контакты
Testimonials	Главная, Отзывы	Отзывы клиентов, оценки, фото
🎯 Примерная структура для React
jsx
// Пример импорта компонентов на странице
import React from 'react';
import Header from './components/Layout/Header/Header';
import Footer from './components/Layout/Footer/Footer';
import Container from './components/Layout/Container/Container';
import Hero from './components/Sections/Hero/Hero';
import Services from './components/Sections/Services/Services';
import Projects from './components/Sections/Projects/Projects';
import Testimonials from './components/Sections/Testimonials/Testimonials';
import Contact from './components/Sections/Contact/Contact';
import Button from './components/UI/Button/Button';
import Card from './components/UI/Card/Card';

function HomePage() {
  return (
    <>
      <Header />
      <main>
        <Hero />
        <Services />
        <Projects />
        <Testimonials />
        <Contact />
      </main>
      <Footer />
    </>
  );
}

export default HomePage;
📱 Адаптивность компонентов
Компонент	Десктоп (≥992px)	Планшет (768-991px)	Мобильный (≤767px)
Header	Горизонтальное меню	Сжатое меню	Бургер-меню
Card Grid	3-4 колонки	2 колонки	1 колонка
Hero	Полная высота	80% высоты	Авто
Modal	Центр экрана	90% ширины	95% ширины
Tabs	Горизонтальные	Горизонтальные (скролл)	Вертикальные
